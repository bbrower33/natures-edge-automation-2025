# Natures Edge Automation Suite (2025)
Google Apps Script automation built and deployed for a live 
landscaping business with 10+ employees.

## What it does
- Sales form submissions automatically populate a CRM sheet
  with client data, quoted price, discount, and sales rep
- Customer quote requests trigger an automated branded HTML
  email confirmation sent to the client within seconds

## Email Preview
![Automated confirmation email]([main/Nature's-Edge-Email.png](https://github.com/bbrower33/natures-edge-automation-2025/issues/1#issue-5366823165))

## Tech
- Google Apps Script (JavaScript)
- Google Sheets API
- Google Forms trigger (onFormSubmit)
- MailApp (Gmail API)

## Impact
Eliminated manual data entry from every sales call and 
automated client communication — saving hours of 
administrative work per week across a 10+ person operation.

## Context
Built and deployed by me as Co-Founder of Nature's Edge 
Landscaping to replace a fully manual intake and 
communication process as the business scaled.
